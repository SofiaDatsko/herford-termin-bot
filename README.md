# Herford Termin Bot

Слідкує за сайтом `terminvergabe.krz.de/0230` (Servicestelle Internationales,
Ersterfassung Ukraineflüchtlinge) і надсилає повідомлення в Telegram, коли
з'являються вільні години на 20.08.2026 або 27.08.2026.

## 1. Встановлення

```bash
pip install -r requirements.txt
playwright install chromium
```

## 2. Дізнатись Chat ID

1. Знайдіть у Telegram бота **@herford_termin_bot** і напишіть йому щось
   (наприклад "привіт").
2. Запустіть:
   ```bash
   python get_chat_id.py
   ```
3. Скопіюйте виведений `chat_id` у `herford_termin_bot.py`, у рядок:
   ```python
   "TELEGRAM_CHAT_ID": "PASTE_YOUR_CHAT_ID_HERE",
   ```

## 3. Перевірка (обов'язково перед фоновим запуском)

Спочатку запустіть з видимим вікном браузера, щоб перевірити, що всі кроки
клікаються правильно:

```bash
python herford_termin_bot.py --once --headed
```

Якщо в консолі з'явиться `Перевірено. Знайдено дати зі слотами: ...` —
все працює. Якщо буде помилка — відкрийте папку `debug/`, там будуть
скріншоти кожного кроку. Надішліть їх мені (і текст помилки з консолі),
і я поправлю селектори під реальну структуру сторінки.

## 4. Постійний моніторинг

```bash
python herford_termin_bot.py
```

Скрипт перевірятиме сайт кожні ~4-5 хвилин (з невеликою випадковою
затримкою, щоб не виглядати як бот) і надішле повідомлення в Telegram,
щойно на одну з дат з'явиться вільний час. **Бот не бронює автоматично** —
лише сповіщає, бронювати треба вручну (слоти зазвичай розбирають швидко).

Щоб бот працював постійно навіть після закриття терміналу — на Windows
можна залишити вікно консолі відкритим або використати Планувальник
завдань; на Linux/macOS — запустити через `nohup`, `screen`, `tmux` або
налаштувати як systemd/launchd сервіс.

## Налаштування

Все конфігурується на початку `herford_termin_bot.py` у словнику `CONFIG`:
дати, текст локації/причини звернення, інтервал перевірки.

## Безпека

Не заповнюйте `TELEGRAM_BOT_TOKEN` у `herford_termin_bot.py` значенням
реального токена, якщо плануєте завантажити файл у репозиторій (навіть
приватний) — токен передається через GitHub Secrets (див. нижче). Якщо
токен все ж кудись "втік" — перевипустіть його через @BotFather (кнопка
"Revoke").

## 5. Постійна робота через GitHub Actions (бот працює навіть коли ПК вимкнено)

Замість того, щоб тримати комп'ютер увімкненим, можна запустити перевірку
на серверах GitHub за розкладом — безкоштовно.

1. Створіть репозиторій на github.com (можна публічний — секрети в ньому
   все одно приховані; для публічного репо ще й немає лімітів на хвилини
   Actions).
2. Завантажте туди всі файли з цієї папки, **включно з прихованою папкою
   `.github/`** (у ній лежить `workflows/check.yml` — саме він і запускає
   перевірку за розкладом).
3. У репозиторії: **Settings → Secrets and variables → Actions → New
   repository secret**. Додайте два секрети:
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `TELEGRAM_CHAT_ID` — ваш chat_id
4. Перейдіть на вкладку **Actions**, знайдіть workflow "Herford Termin
   Check", натисніть **Run workflow**, щоб перевірити вручну першого разу.
5. Якщо все ок — далі він сам запускатиметься кожні ~10 хвилин і
   надсилатиме повідомлення в Telegram, коли зʼявляться вільні години.

Детальна покрокова інструкція (як створити репозиторій, куди тиснути) —
проговоримо окремо, якщо потрібно, з урахуванням того, що ви завантажите
через сайт github.com або через Visual Studio.
